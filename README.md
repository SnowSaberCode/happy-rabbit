# 🐇 快乐兔园 - Happy Rabbit Garden

2D像素风格休闲养成游戏，用Godot 4.7开发。

## 项目简介

在围栏里饲养可爱的垂耳兔，给它们喂食、喂水、抚摸互动，定期剃毛获得金币，收集便便换取收入，完成成长任务解锁更多物品，用金币购买更多兔子、食物、玩具和自动设施。

## 游戏机制 🎮

### 兔子属性
| 属性 | 说明 | 变化 |
|------|------|------|
| 🍖 饱食度 | 兔子的饥饿程度 | 随时间下降，喂食增加 |
| 💧 口渴度 | 兔子的口渴程度 | 随时间下降，喂水增加 |
| 😊 快乐值 | 兔子的心情 | 随时间下降，抚摸/玩具增加 |
| ✂️ 毛长度 | 可以剃毛赚钱 | 随时间增长，剃毛重置 |
| ❤️ 健康值 | 受其他属性影响 | 综合状态良好时恢复 |

## 使用说明 📖

1. 用Godot 4.7打开项目
2. 点击运行按钮（F5）开始游戏
3. 初始有3只兔子：萝小草、萝大壮、萝二白
4. **基础操作**：
   - 点击兔子选中，查看详细属性
   - 使用底部按钮与兔子互动：
     - 🥕 喂食：增加饱食度
     - 💧 喂水：增加口渴度
     - 🤚 抚摸：增加快乐值，获得10金币
     - ✂️ 剃毛：毛长≥80时可剃毛获得金币
   - 点击围栏里的 💩 收集便便，获得金币
5. **顶部栏**：
   - 🏪 商店：购买食物、玩具、药品、设施或新兔子
   - 🎒 背包：查看和使用物品
   - 🌱 成长：查看成长任务进度，领取奖励
   - 💾 存档：保存/加载游戏
6. **成长任务**：
   - 任务按顺序解锁，完成上一个才能进行下一个
   - 完成任务后在成长面板领取奖励
   - 每个任务解锁一种新的商店物品
7. **设施系统**：
   - 购买设施后会自动放置在围栏内
   - 可以拖拽移动设施位置
   - **双击**喂食器/饮水器/木屋可以存放物资
   - 自动马桶会每30秒自动收集所有便便
8. **自动设施**：
   - 放入物资后，设施会自动工作
   - 每3秒给所有兔子增加属性
   - 消耗完物资需要重新添加
9. **围栏扩建**：
   - 初始最多养3只兔子
   - 在商店「兔子」标签页购买围栏扩建，每次增加1个名额

## 技术特点 🔧

- **单例模式**：GameManager、SaveManager、AudioManager、InventoryManager、TaskManager、UnlockTaskManager全局可访问
- **信号系统**：Godot信号处理UI更新和交互事件
- **物品数据管理**：ItemData统一管理所有物品配置
- **设施管理器**：InventoryManager处理背包和放置设施
- **AI状态机**：兔子根据状态自动切换行为
- **响应式UI**：选中兔子实时更新属性显示
- **定时器系统**：设施效果和自动喂食定时触发
- **阶梯任务系统**：线性任务链，逐步解锁新物品，引导玩家体验完整玩法
